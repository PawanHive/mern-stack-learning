# #3: Steps to SETUP Redux 

## Step 1: Create React App

```terminal
npm create vite@latest
```

## Step 2: Install Redux Toolkit

```terminal
npm install @reduxjs/toolkit
```

## Step 3: Install React-Redux

```terminal
npm install react-redux
```

## Step 4: Start server

```terminal
npm run dev
```
